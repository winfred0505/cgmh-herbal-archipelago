## 一、REA 逆向工程分析：「政策島」(`https://puma.taipei/heart-island`) 設計架構解構

透過 REA 執行線上瀏覽器情境擷取（`capture_browser_scenario`，Evidence ID: `ev_b3a8bba093dc439390eeeba38243424ca748aadaa0a110537d6560c21b53c679`）與靜態 JavaScript 語意應用程式圖譜分析（`analyze_javascript_application`，Evidence ID: `ev_f861cd68f140a30ea0501acd498b2bf405ed14c42e6d63c97ec8368c904d7f51` / `ev_93735c96d8fbe8a77bba0afbc52919d17473061186eba22b63f2c0de3a036002`），解構出「政策島」的核心設計架構：

1. **六角軸向坐標系與台灣／城市輪廓拼接 (`world.js`)**
   - 採用軸向坐標 $(q, r)$ 轉 3D 世界坐標公式：
     $$x = \sqrt{3} \cdot S \cdot \left(q + \frac{r}{2}\right), \quad z = 1.5 \cdot S \cdot r$$
   - 每座六角島由**四層結構**組成：淺灘水環 (`SHALLOW_TONE`)、頂點雜訊位移之分層岩壁 (`cliffGeometry` + `CLIFF` 岩層色階)、外圈環島步道 (`RING_TINT`)，以及 256×256 `CanvasTexture` 程序化生成之主題地表紋理（花崗岩、草坪、陶磚、木棧道、農田、中庭等）。
   - 透過六方向鄰接向量 `NEIGHBORS` 自動偵測相鄰島嶼（$\Delta \text{hex} = 1$），自動架設跨海微縮拱橋。

2. **微縮積木建築工廠與語意地標 (`kit.js` + `scene-models.js` + `decor.js`)**
   - 每座六角島內部配置 4–6 座可獨立點選的微縮子建築（標示為 `①`、`②`、`③`...），由基本幾何體（歇山頂 `hip`、圓頂 `dome`、發光窗 `glowbox`、圓柱 `cylinder`）組合而成。
   - 外圈步道頂點自動配置微縮路燈（夜晚自動點亮暖黃光暈）與植栽花圃。

3. **24 小時大氣光影與波光海面 Shader (`environment.js`)**
   - 自訂 `ShaderMaterial` 天空穹頂（含太陽方向高光與夜間程序化星點）與海面波紋 Shader。
   - 依據一天 0–1440 分鐘關鍵影格 (`KEYS`) 動態插值天頂色、地平線霧色、半球光、太陽仰角陰影與建築窗戶自發光強度。

4. **跨島協作線與雙層資訊介面 (`app.js` + `ui.css` + `policies.json`)**
   - 以奶油米 (`#fff8f4`)、珊瑚朱砂 (`#db6a41`)、深墨色 (`#211d1d`) 與暖黃 (`#fcea8b`) 構成高辨識度編輯感 UI。
   - 包含：3D 投影浮動島嶼名牌 (`#labels`)、右側三合一可展開索引樹 (`#sidebar`)、滑出式詳情卡 (`#card`)、底部快速跳島列 (`#dock`)、左下角時間軸與篩選控制台 (`section.controls`)、右上角圖層開關 (`.hud`) 與即時城市日誌 (`#log`)。

## 四、啟動方式

1. **直接雙擊開啟**：直接雙擊 `index.html`（已將 34 組 `.glb` 3D 模型預先封裝於 `assets/models_bundle.js`，即使在 `file:///` 離線模式下亦零 CORS 限制，完整呈現骨骼動畫與 3D 場景）。
2. **一鍵啟動伺服器**：雙擊 `開啟長庚中藥群島.bat`，自動開啟 `http://localhost:8092/index.html`。
